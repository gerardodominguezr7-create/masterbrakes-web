# MASTERBRAKES · Página de reserva para Google

La nueva página es:

- https://www.frenosmasterbrakes.com/reserva.html

Para que cada Perfil de Empresa de Google abra la reserva con su sucursal ya seleccionada, usa estos enlaces:

- Sombrerete: https://www.frenosmasterbrakes.com/reserva.html?sucursal=sombrerete
- Pie de la Cuesta: https://www.frenosmasterbrakes.com/reserva.html?sucursal=pie-de-la-cuesta

## Cómo funciona

1. El cliente elige sucursal, servicio, vehículo, fecha y hora preferida.
2. La página genera la solicitud y la envía por WhatsApp al número de la sucursal seleccionada.
3. El sitio aclara que el horario queda confirmado únicamente cuando MASTERBRAKES responde.

## En Google

Una vez publicada la web en el dominio, coloca el enlace correspondiente en el campo de enlace de citas / reservas del Perfil de Empresa de cada sucursal.

No requiere una base de datos ni un sistema de pago. Si después se necesita disponibilidad en tiempo real o confirmación automática, habría que conectar un calendario o un sistema de reservas externo.
